# Email Sending Utility

This utility file provides functions for sending emails using the AWS Simple Email Service (SES). It abstracts the complexities of constructing SES commands and handles sending emails to specified recipients.

## Overview

The `sendEmail.js` file is a utility that leverages the AWS SDK for JavaScript to interact with Amazon SES. Its primary purpose is to facilitate sending emails from the backend application, abstracting the underlying SES API calls. This module is crucial for any feature requiring email notifications, such as account verification, password resets, or system alerts.

## Parameters / Configuration

This utility does not directly accept configuration parameters upon import. Instead, it relies on the pre-configured `sesClient` utility to establish a connection to AWS SES.

## Functions

### `run()`

Sends an email using the configured AWS SES client.

This function constructs an email message and sends it to the specified recipient using AWS SES. It handles potential `MessageRejected` errors specifically.

<Info>
This function assumes that the `sesClient` has been properly configured with AWS credentials and region. It also expects a valid `toAddress` and `fromAddress` to be used within its internal `createSendEmailCommand` function. The HTML and Text bodies, as well as the subject, are currently hardcoded within `createSendEmailCommand` and would need customization for dynamic content.
</Info>

```javascript
const { sesClient } = require("./sesClient"); // Assumes sesClient is configured

const run = async () => {
  // Internal function to create the SES command
  const createSendEmailCommand = (toAddress, fromAddress) => {
    return new SendEmailCommand({
      Destination: {
        ToAddresses: [toAddress],
      },
      Message: {
        Body: {
          Html: {
            Charset: "UTF-8",
            Data: "HTML_FORMAT_BODY", // TODO: Make dynamic
          },
          Text: {
            Charset: "UTF-8",
            Data: "TEXT_FORMAT_BODY", // TODO: Make dynamic
          },
        },
        Subject: {
          Charset: "UTF-8",
          Data: "EMAIL_SUBJECT", // TODO: Make dynamic
        },
      },
      Source: fromAddress,
    });
  };

  const sendEmailCommand = createSendEmailCommand(
    "eurydomeadvisorspvtltd@gmail.com", // Placeholder recipient
    "yashnirwan18@gmail.com",         // Placeholder sender
  );

  try {
    return await sesClient.send(sendEmailCommand);
  } catch (caught) {
    if (caught instanceof Error && caught.name === "MessageRejected") {
      /** @type { import('@aws-sdk/client-ses').MessageRejected} */
      const messageRejectedError = caught;
      return messageRejectedError;
    }
    throw caught;
  }
};
```

## Usage Example

Here's an example of how you might call the `run` function from another part of your application to send an email.

<Tip>
For dynamic email content, you would typically modify the `createSendEmailCommand` function or pass content as parameters to the `run` function.
</Tip>

```javascript
const { run } = require('../utils/sendEmail'); // Assuming this file is in src/utils

// ... within another module, e.g., a controller or service

const sendWelcomeEmail = async (userEmail) => {
  try {
    // In a real application, the fromAddress would likely come from configuration
    const emailResult = await run(userEmail, 'noreply@yourdomain.com');

    if (emailResult.MessageId) {
      console.log(`Email sent successfully to ${userEmail}. Message ID: ${emailResult.MessageId}`);
    } else {
      console.error(`Failed to send email. Rejected reason: ${emailResult.MessageRejected}`);
    }
  } catch (error) {
    console.error(`Error sending email:`, error);
  }
};

// Example usage:
// sendWelcomeEmail('newuser@example.com');
```

## Common Errors / Troubleshooting

<AccordionGroup>
  <Accordion title="MessageRejected Error">
    This error typically occurs when AWS SES rejects the email for reasons such as:
    <ul>
      <li>The sender email address is not verified in SES.</li>
      <li>The recipient email address is not verified and SES is in sandbox mode.</li>
      <li>The email content violates SES sending policies.</li>
    </ul>
    <Tip>
    Ensure your sender (`fromAddress`) and recipient (`toAddress`) are verified in your AWS SES console. If you are in the SES sandbox, you must verify all recipient email addresses.
    </Tip>
  </Accordion>
  <Accordion title="AWS Credentials Error">
    If you encounter errors related to authentication or authorization, it means the `sesClient` is not properly configured with valid AWS credentials or permissions.
    <Warning>
    Never hardcode AWS credentials directly in your code. Use environment variables or IAM roles for secure credential management.
    </Warning>
  </Accordion>
</AccordionGroup>
