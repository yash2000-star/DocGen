# User Model

This file defines the Mongoose schema and methods for user data, handling user authentication, profile information, and related logic.

## Overview

The `User` model is central to the application, representing individual users. It includes fields for profile details, authentication credentials, and user status (e.g., premium membership). This model interacts with the database to store and retrieve user information and provides methods for generating JWTs and validating passwords.

## Methods

### getJWT

Generates a JSON Web Token (JWT) for the user.

```javascript
userSchema.methods.getJWT = async function () {
    const user = this;

    const token = await jwt.sign({ _id: user._id }, "DEV@Tinder$790", {
                expiresIn: "1d"
            });

            return token;
}
```

<Note>
The JWT secret `DEV@Tinder$790` should be stored securely in environment variables and not hardcoded.
</Note>

### validatePassword

Compares a provided password against the user's hashed password.

```javascript
userSchema.methods.validatePassword = async function (passwordInputByUser) {
    const user = this;
    const passwordHash = user.password;

    const isPasswordVaild = await bcrypt.compare(passwordInputByUser, passwordHash);

    return isPasswordVaild;
}
```

<Warning>
Ensure that passwords are always hashed using `bcrypt` before storing them in the database.
</Warning>

## Usage Example

This model is typically used in authentication routes (e.g., `src/routes/auth.js`) and controllers to find, create, or update user records.

Here's an example of how you might use the `User` model to find a user and generate a token:

```javascript
const User = require('../models/user');

async function loginUser(email, password) {
  try {
    const user = await User.findOne({ emailId: email });

    if (!user) {
      throw new Error('Invalid login credentials');
    }

    const isMatch = await user.validatePassword(password);

    if (!isMatch) {
      throw new Error('Invalid login credentials');
    }

    const token = await user.getJWT();
    return { user, token };

  } catch (error) {
    console.error("Login error:", error);
    throw error; // Re-throw the error to be handled by the caller
  }
}
```

<Tip>
It's recommended to use environment variables for sensitive information like JWT secrets to enhance security.
</Tip>
