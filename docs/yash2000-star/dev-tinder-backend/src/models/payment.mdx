# `Payment` Mongoose Model

This file defines the Mongoose schema and model for `Payment` documents, establishing the data structure for all payment-related information stored in the database. It handles the validation and persistence layer for payment records.

## Overview

The `Payment` model is central to tracking all financial transactions within the system. It links payments to specific users and stores critical details such as payment IDs, order IDs, amounts, currencies, and transaction statuses. This model is primarily interacted with by the payment processing routes defined in `src/routes/payment.js` to create, update, and retrieve payment records.

<Info>
  This model integrates with the `User` model via the `userId` field to establish a clear relationship between payments and their associated users.
</Info>

## Model Fields

The `Payment` model is defined with the following fields:

<ParamField name="userId" type="mongoose.Types.ObjectId" required>
  The unique identifier of the user who made the payment. This field references the `User` model.
</ParamField>

<ParamField name="paymentId" type="string">
  The unique ID generated by the payment gateway (e.g., Razorpay) for the transaction. This field is optional during initial order creation but populated upon successful payment.
</ParamField>

<ParamField name="orderId" type="string" required>
  The unique ID for the payment order, typically generated before initiating the payment gateway process.
</ParamField>

<ParamField name="status" type="string" required>
  The current status of the payment. Examples include `pending`, `successful`, `failed`, `refunded`.
</ParamField>

<ParamField name="amount" type="number" required>
  The total amount of the payment, in the smallest currency unit (e.g., cents for USD).
</ParamField>

<ParamField name="currency" type="string" required>
  The three-letter ISO 4217 currency code for the payment (e.g., `INR`, `USD`).
</ParamField>

<ParamField name="receipt" type="string" required>
  A unique identifier for the payment receipt, typically provided by the payment gateway or generated internally.
</ParamField>

<ParamField name="notes" type="object">
  <Expandable title="notes properties">
    <ParamField name="notes.firstName" type="string">
      The first name of the person associated with the payment.
    </ParamField>
    <ParamField name="notes.lastName" type="string">
      The last name of the person associated with the payment.
    </ParamField>
    <ParamField name="notes.membershipType" type="string">
      The type of membership purchased, if applicable (e.g., `premium`, `gold`).
    </ParamField>
  </Expandable>
  Additional custom information or metadata related to the payment.
</ParamField>

<ParamField name="createdAt" type="Date">
  Automatically generated timestamp indicating when the payment record was created.
</ParamField>

<ParamField name="updatedAt" type="Date">
  Automatically generated timestamp indicating the last time the payment record was updated.
</ParamField>

#### Updating a Payment Record

<ParamField name="query" type="object" required>
  The query to find the payment record(s) to update.
</ParamField>

<ParamField name="update" type="object" required>
  The update operations to apply to the matched documents.
</ParamField>

<ParamField name="options" type="object">
  Optional Mongoose query options, such as `{ new: true }` to return the updated document.
</ParamField>

<ResponseField name="result" type="object">
  The result of the update operation, typically including `nModified` and `upserted` counts. If `new: true` option is used, the updated document is returned.
</ResponseField>

<CodeGroup>
```javascript Updating Payments
const Payment = require('../models/payment');

async function updatePaymentStatus(orderId, newStatus, paymentId = null) {
  try {
    const updatePayload = { status: newStatus };
    if (paymentId) {
      updatePayload.paymentId = paymentId; // Set paymentId if provided (e.g., after successful transaction)
    }

    const updatedPayment = await Payment.findOneAndUpdate(
      { orderId },
      { $set: updatePayload },
      { new: true } // Return the updated document
    );

    if (!updatedPayment) {
      console.log('Payment with provided orderId not found for update.');
      return null;
    }
    console.log('Payment updated:', updatedPayment);
    return updatedPayment;
  } catch (error) {
    console.error('Error updating payment status:', error);
    throw error;
  }
}
```

## Usage Example

This example demonstrates a typical flow involving the `Payment` model: creating a pending payment, and then updating its status once a transaction is confirmed.

<CodeGroup>
```javascript JavaScript
const Payment = require('./src/models/payment'); // Adjust path as necessary
const mongoose = require('mongoose');

async function handlePaymentFlow(userId) {
  // 1. Generate a unique order ID (this would typically come from a payment gateway integration)
  const generatedOrderId = `order_${Math.random().toString(36).substring(2, 15)}`;
  const exampleReceipt = `receipt_${Math.random().toString(36).substring(2, 10)}`;

  // 2. Create a pending payment record
  console.log('Creating pending payment record...');
  let pendingPayment;
  try {
    pendingPayment = await Payment.create({
      userId: new mongoose.Types.ObjectId(userId),
      orderId: generatedOrderId,
      amount: 2999, // e.g., $29.99
      currency: 'USD',
      receipt: exampleReceipt,
      status: 'pending',
      notes: { membershipType: 'premium_monthly' }
    });
    console.log('Pending payment created:', pendingPayment);
  } catch (error) {
    console.error('Failed to create pending payment:', error);
    return;
  }

  // Simulate a payment gateway interaction...
  console.log('\nSimulating payment gateway processing for order:', generatedOrderId);
  const paymentSuccessful = Math.random() > 0.1; // 90% chance of success
  const gatewayPaymentId = paymentSuccessful ? `pay_${Math.random().toString(36).substring(2, 10)}` : null;

  // 3. Update the payment record based on gateway response
  console.log('Updating payment status...');
  let finalStatus = paymentSuccessful ? 'successful' : 'failed';
  try {
    const updatedPayment = await Payment.findOneAndUpdate(
      { orderId: generatedOrderId },
      {
        $set: {
          status: finalStatus,
          paymentId: gatewayPaymentId // Populate paymentId if successful
        }
      },
      { new: true }
    );
    console.log('Payment updated:', updatedPayment);
    return updatedPayment;
  } catch (error) {
    console.error('Failed to update payment status:', error);
    return;
  }
}
```

## Common Errors / Troubleshooting

<AccordionGroup>
  <Accordion title="Missing required fields when creating a payment">
    <Danger>
      Attempting to create a `Payment` document without providing values for `userId`, `orderId`, `status`, `amount`, `currency`, or `receipt` will result in a Mongoose `ValidationError`.
    </Danger>
    Ensure all `required: true` fields in the `paymentSchema` are present in the data object passed to `Payment.create()` or `new Payment()`. Check your server logs for specific `ValidationError` messages.
    <CodeGroup>
```javascript Incorrect Example
const Payment = require('../models/payment');
// This will fail because orderId, amount, currency, receipt, and status are missing
await Payment.create({ userId: 'someUserId' });
```
```javascript Correct Example
const Payment = require('../models/payment');
await Payment.create({
  userId: new mongoose.Types.ObjectId('60c72b1f9e2b1c001f8e1a1b'),
  orderId: 'ORD_12345',
  amount: 1000,
  currency: 'INR',
  receipt: 'REC_abc',
  status: 'pending'
});
```
    </Accordion>
    <Accordion title="`userId` is not a valid ObjectId">
      <Warning>
        If `userId` is provided as a plain string that is not a valid 24-character hexadecimal string, Mongoose will throw a `CastError` when trying to save or query.
      </Warning>
      Always ensure `userId` values are valid `mongoose.Types.ObjectId` instances. If you receive the ID as a string from a client or another service, cast it using `new mongoose.Types.ObjectId(userIdString)`.
      <CodeGroup>
```javascript Invalid userId (causes CastError)
const Payment = require('../models/payment');
await Payment.create({
  userId: 'not-an-objectid-string', // This will fail
  orderId: 'ORD_12345',
  amount: 1000,
  currency: 'INR',
  receipt: 'REC_abc',
  status: 'pending'
});
```
```javascript Valid userId
const Payment = require('../models/payment');
const mongoose = require('mongoose');
await Payment.create({
  userId: new mongoose.Types.ObjectId('60c72b1f9e2b1c001f8e1a1b'), // Correct
  orderId: 'ORD_12345',
  amount: 1000,
  currency: 'INR',
  receipt: 'REC_abc',
  status: 'pending'
});
```
    </Accordion>
    <Accordion title="Payment record not found for update">
      If `Payment.findOneAndUpdate()` or `Payment.findByIdAndUpdate()` returns `null`, it means no document matched the provided query.
      <Check>
        Verify that the `orderId` or `_id` you are using in your update query actually exists in the database.
      </Check>
      Ensure there are no typos in the query fields or values. It's good practice to check if the returned document is `null` and handle that case in your application logic.
    </Accordion>
