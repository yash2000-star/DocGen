# Database Connection Configuration

This file, `src/config/database.js`, is responsible for establishing and managing the application's connection to the MongoDB database using Mongoose. It centralizes the database connection logic, ensuring a consistent and secure approach to interacting with the data layer.

## Overview

The `database.js` module provides a single asynchronous function, `connectDB`, which initiates the connection to a MongoDB instance. It leverages environment variables for sensitive connection details, promoting best practices for security and configuration management. This configuration ensures that all models defined in the `src/models` directory (e.g., `src/models/user.js`, `src/models/chat.js`) can interact with the database once the connection is established.

## Setup

Before the application can connect to the database, you must configure the `DB_CONNECTION_SECRET` environment variable.

<Steps>
  <Step title="Create an environment file">
    Create a `.env` file in the root directory of your project if one doesn't already exist.
    <Note>
      For production environments, ensure these variables are managed securely via your hosting provider's configuration panel, not directly in a `.env` file.
    </Note>
  </Step>
  <Step title="Set the DB_CONNECTION_SECRET">
    Add your MongoDB connection string to the `.env` file. This string typically includes the database host, port, authentication details, and the database name.
    <Warning>
      The `DB_CONNECTION_SECRET` contains sensitive credentials. Never commit your `.env` file to version control. Add `.env` to your `.gitignore`.
    </Warning>
    ```dotenv
    DB_CONNECTION_SECRET="mongodb://localhost:27017/dev-tinder"
    # Or for a remote database:
    # DB_CONNECTION_SECRET="mongodb+srv://user:password@cluster0.abcde.mongodb.net/dev-tinder?retryWrites=true&w=majority"
    ```
  </Step>
</Steps>

## Configuration

The `connectDB` function relies on a critical environment variable for its operation.

<ParamField name="DB_CONNECTION_SECRET" type="string" required>
  The MongoDB connection URI. This string specifies the database server address, authentication credentials, and other connection options. It is crucial for the application to establish a link with your MongoDB instance.
  <Danger>
    Incorrectly configuring or exposing this secret can lead to database connection failures, security breaches, and unauthorized data access. Always protect this value.
  </Danger>
</ParamField>

## Functions

### `connectDB`

An asynchronous function that establishes a connection to the MongoDB database using the URI provided in the `DB_CONNECTION_SECRET` environment variable.

<ResponseField name="Promise<void>" type="Promise">
  A Promise that resolves upon successful connection to the MongoDB database. If the connection fails, the promise will reject, and the application should handle the error (e.g., exit gracefully or log the error).
</ResponseField>

```javascript
const mongoose = require("mongoose");

const connectDB = async () => {
   try {
     await mongoose.connect(process.env.DB_CONNECTION_SECRET);
     console.log("MongoDB connected successfully.");
   } catch (error) {
     console.error("MongoDB connection failed:", error.message);
     process.exit(1); // Exit process with failure
   }
};

module.exports = connectDB;
```

## Usage Example

The `connectDB` function is typically called once during application startup, usually in the main entry file (`src/app.js`), to ensure the database connection is active before handling requests.

<CodeGroup>
```javascript src/app.js
const express = require('express');
const connectDB = require('./config/database'); // Import the connectDB function

const app = express();

// Connect to the database
connectDB();

// Your middleware and route definitions would go here
// For example:
// app.use('/api/auth', require('./routes/auth'));

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
```
</CodeGroup>

## Common Errors / Troubleshooting

<AccordionGroup>
  <Accordion title="Database connection failed (MongooseServerSelectionError)">
    This error typically indicates that Mongoose could not reach the MongoDB server at the specified address.
    <Steps>
      <Step title="Check DB_CONNECTION_SECRET">
        Verify that your `DB_CONNECTION_SECRET` environment variable is correctly set and points to an accessible MongoDB instance. Ensure there are no typos, and the format is correct (e.g., `mongodb://localhost:27017/dbname` or `mongodb+srv://...`).
      </Step>
      <Step title="Ensure MongoDB is running">
        Confirm that your MongoDB server (local or remote) is up and running and accessible from where your application is hosted. For local installations, start the MongoDB service. For cloud databases, check their status page.
      </Step>
      <Step title="Network access">
        If using a cloud-hosted MongoDB (like MongoDB Atlas), ensure that your application's IP address is whitelisted in the database's network access settings.
      </Step>
    </Steps>
  </Accordion>
  <Accordion title="Authentication errors (MongooseError: Authentication failed)">
    This error occurs when the database connection string contains incorrect username or password credentials.
    <Steps>
      <Step title="Verify credentials">
        Double-check the username and password embedded in your `DB_CONNECTION_SECRET`. For cloud databases, ensure the user has appropriate permissions for the database you are trying to connect to.
      </Step>
      <Step title="Check database user roles">
        Ensure the specified user has the necessary roles (e.g., `readWrite`) for the target database.
      </Step>
    </Steps>
  </Accordion>
</AccordionGroup>
