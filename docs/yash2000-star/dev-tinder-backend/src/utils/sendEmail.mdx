# sendEmail.js - AWS SES Email Utility

This utility file is responsible for sending emails using the Amazon Simple Email Service (SES). It leverages the `@aws-sdk/client-ses` to interact with AWS, primarily for notification or transactional email purposes within the `dev-tinder-backend` application.

## Overview

The `sendEmail.js` module provides a single exported function, `run`, which facilitates sending a predefined email. It depends on `src/utils/sesClient.js` for AWS SES client configuration and authentication. As currently implemented, this module is designed for a very specific email sending task, with recipient, sender, subject, and body content hardcoded within its internal logic.

<Info>
  This utility relies on `src/utils/sesClient.js` to establish a connection with AWS SES. Ensure your AWS credentials are
  correctly configured for the SES client to function.
</Info>

## Functions

This module contains one exported function (`run`) and one internal helper function (`createSendEmailCommand`).

### `run()`

Sends a predefined email using AWS SES with hardcoded recipient, sender, subject, and body. This function serves as the primary entry point for sending a specific email notification.

<Warning>
  **Fixed Email Content:** As currently implemented, the `run` function sends an email with a fixed recipient (`eurydomeadvisorspvtltd@gmail.com`), a fixed sender (`yashnirwan18@gmail.com`), and placeholder subject (`EMAIL_SUBJECT`) and body content (`HTML_FORMAT_BODY`, `TEXT_FORMAT_BODY`). It is not a generic email sending utility without modification.
</Warning>

#### Parameters

This function does not accept any parameters.

#### Returns

<ResponseField name="Promise<SendEmailCommandOutput | MessageRejected | Error>" type="object">
  A Promise that resolves with the result of the AWS SES `send` operation if successful.
  If the message is rejected by SES, it returns a `MessageRejected` error object.
  Other errors during the sending process will be rethrown.
</ResponseField>

#### Example

```javascript
const { run: sendSpecificEmail } = require('../utils/sendEmail');

async function initiateSpecificEmailProcess() {
  try {
    const result = await sendSpecificEmail();
    if (result && result.$metadata && result.$metadata.httpStatusCode === 200) {
      console.log('Email sent successfully:', result.MessageId);
    } else if (result.name === 'MessageRejected') {
      console.error('Email rejected by SES:', result.message);
    } else {
      console.error('Failed to send email:', result);
    }
  } catch (error) {
    console.error('An unexpected error occurred:', error);
  }
}

initiateSpecificEmailProcess();
```

### `createSendEmailCommand(toAddress, fromAddress)`

An internal helper function that constructs an `SES.SendEmailCommand` object for dispatching an email. This command object specifies the destination, source, subject, and body of the email.

<Note>
  This function is an internal utility used by the exported `run` function. While it accepts `toAddress` and `fromAddress`, the email's subject and body content (`EMAIL_SUBJECT`, `HTML_FORMAT_BODY`, `TEXT_FORMAT_BODY`) are hardcoded within this function definition.
</Note>

#### Parameters

<ParamField name="toAddress" type="string" required>
  The email address of the primary recipient.
</ParamField>
<ParamField name="fromAddress" type="string" required>
  The email address of the sender. This address must be verified in AWS SES.
</ParamField>

#### Returns

<ResponseField name="SendEmailCommand" type="object">
  An instance of `SendEmailCommand` from `@aws-sdk/client-ses`, configured with the provided addresses and internal hardcoded subject/body.
</ResponseField>

## Usage Example

To send the pre-configured email using this utility, simply import and call the `run` function.

```javascript
const { run: sendEmailUtility } = require('./src/utils/sendEmail');

async function sendPredefinedEmail() {
  console.log('Attempting to send the predefined email...');
  try {
    const response = await sendEmailUtility();
    if (response && response.MessageId) {
      console.log(`Predefined email sent successfully. Message ID: ${response.MessageId}`);
    } else if (response && response.name === 'MessageRejected') {
      console.error(`Predefined email rejected by SES: ${response.message}`);
    } else {
      console.error('Failed to send predefined email:', response);
    }
  } catch (error) {
    console.error('Error sending predefined email:', error);
  }
}

sendPredefinedEmail();
```

## Common Errors / Troubleshooting

<AccordionGroup>
  <Accordion title="`MessageRejected` Error">
    This error occurs when AWS SES rejects the email sending request. Common reasons include:
    <ul>
      <li>**Unverified Sender:** The `fromAddress` (`yashnirwan18@gmail.com` in this case) has not been verified in your AWS SES account.</li>
      <li>**Recipient Not Verified (in Sandbox):** If your AWS SES account is in sandbox mode, the `toAddress` (`eurydomeadvisorspvtltd@gmail.com`) must also be verified in SES.</li>
      <li>**Content Violations:** The email content might contain spam-like characteristics or violate AWS SES sending policies.</li>
    </ul>
    <Tip>
      Ensure both sender and recipient email addresses are verified in your AWS SES console if you are operating in sandbox mode. For production, only the sender needs to be verified.
    </Tip>
  </Accordion>
  <Accordion title="AWS Credentials Not Found">
    If you encounter errors related to missing AWS credentials or inability to authenticate with AWS, verify that your environment variables (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`) are correctly set up and accessible to the application, or that you have configured an IAM role for your compute environment.
    <Info>
      The `sesClient` (from `src/utils/sesClient.js`) automatically picks up credentials from standard AWS locations, including environment variables and shared credential files.
    </Info>
  </Accordion>
</AccordionGroup>
